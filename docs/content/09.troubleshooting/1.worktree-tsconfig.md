---
title: Worktree tsconfig error
description: "TSCONFIG_ERROR … ../../../.nuxt/tsconfig.json" when the project sits inside another checkout.
---

## Symptom

Every page fails with a Vite compile error, or `pnpm run build` stops with:

```
[TSCONFIG_ERROR] Failed to load tsconfig '../../../.nuxt/tsconfig.json': Tsconfig not found
```

## Cause

Vite 8 transforms TypeScript with OXC, which looks for the `tsconfig.json` that *includes* the file. A `tsconfig.json` doesn't include `.vue` files by default, so for pages and components OXC keeps walking up the directory tree. When this checkout is a git worktree inside another checkout (e.g. `<repo>/.claude/worktrees/<name>`), it reaches the **parent checkout's** `tsconfig.json`, which extends `./.nuxt/tsconfig.json`. If the parent has never been installed, that file doesn't exist and the transform fails.

A standalone clone has no parent `tsconfig.json`, so it never hits this.

## Fix

Give the parent checkout its generated tsconfig — either properly:

```bash
cd <parent checkout> && pnpm install   # runs nuxt prepare
```

or with a placeholder (the folder is gitignored and regenerated by Nuxt):

```bash
mkdir -p <parent checkout>/.nuxt
echo '{ "compilerOptions": {} }' > <parent checkout>/.nuxt/tsconfig.json
```

Then restart the dev server — Vite caches tsconfig lookups.
