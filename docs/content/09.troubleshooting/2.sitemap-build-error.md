---
title: Nitro build fails on the sitemap
description: '"The path argument must be of type string" while building the Nitro server.'
---

## Symptom

The dev server hangs on *Building server*, or `pnpm run build` fails with:

```
[nitro] ERROR TypeError [ERR_INVALID_ARG_TYPE]: The "path" argument must be of type string. Received undefined
    at findPackageJson (@rollup/plugin-node-resolve …)
```

## Cause

`sitemap: { enabled: false }` in `nuxt.config.ts`. The sitemap module (part of `@nuxtjs/seo`) still emits an import of `#sitemap-virtual/static-config.mjs`, but the virtual module isn't registered when the module is disabled, so Rollup tries to resolve it as a package import without an importer and crashes.

## Fix

Don't disable the sitemap this way. The app keeps search engines out with `robots: { disallow: ['/'] }`, and every page requires a login, so an (empty) sitemap is harmless.

## Finding issues like this

When Rollup fails without saying which import, temporarily log in `resolvePackageImports` in `node_modules/@rollup/plugin-node-resolve/dist/es/index.js`:

```js
if (!importer) console.log('no importer for', importSpecifier);
```
