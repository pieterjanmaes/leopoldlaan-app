## Stack

| Layer | Choice |
|---|---|
| Framework | Nuxt 4 (`app/` source dir), SSR on Cloudflare Workers |
| UI | Nuxt UI v4 dashboard components + Tailwind CSS v4, Dutch only |
| Data | D1 (SQLite) through NuxtHub's `hub:db`, Drizzle ORM |
| Auth | `nuxt-auth-utils` sessions, scrypt hashing, Turnstile on login |
| Files | Google Drive REST v3, proxied by the server |
| Canvas | `vue-konva` for the floor plan |

## Request flow

```
page  ──useFetch──▶  server/api/<route>.<method>.ts
                         │ requireUser / requireInternal / requireOwner
                         │ getValidatedRouterParams / readValidatedBody (Zod from shared/schemas)
                         ▼
                     server/utils/*  ──▶  db (hub:db) / Google Drive
                         │
                         ▼
                     view object (shared/types/api.ts) ──▶ JSON
```

Endpoints stay thin: validation and guards at the top, logic in `server/utils/`, and a `to…View()` mapper that turns rows into the JSON shape the UI expects.

## Conventions

- **Money is integer cents.** `formatPrice` / `formatPriceRounded` (`shared/utils/money.ts`) format in nl-BE; `CPriceInput` edits euros while its model stays in cents.
- **Calendar dates are `'YYYY-MM-DD'` strings**, never `Date`. Arithmetic uses UTC day numbers (`shared/utils/dates.ts`); display uses `toDate()` which parses at local noon. Moments (created, done, logged in) are timestamps.
- **Enums and labels** live in `shared/utils/constants.ts` (`TASK_STATUS_META`, `QUOTE_STATUS_META`, …), shared by schema, API and UI.
- **Input schemas** are Zod objects in `shared/schemas/`, used by both `UForm` and the endpoint. Optional text fields are `null` when empty (`useNullableText`).
- **Mutations** go through `useAction()` — it ignores double clicks, can ask for confirmation, shows a success toast and routes errors to `useApiError()`, which shows the server's Dutch message.
- **Shared data** uses fixed `useFetch` keys (`'tasks'`, `'lookups'`, `'project'`, …) so the layout and pages share one request and one refresh.
- **Pages** wrap content in `CPage` (`UDashboardPanel` + navbar + optional toolbar, with room for the mobile bottom bar).
- **Server imports** of shared code use explicit relative paths, so they work in plain-Node unit tests too.

## Language

`@nuxtjs/i18n` is configured with a single `nl` locale and `strategy: 'no_prefix'`, so URLs carry no locale prefix. UI strings are written in Dutch directly in the components; there are no translation files to maintain. Nuxt UI's own strings use its `nl` locale (`app/app.vue`), and Zod's validation messages are Dutch via `useZodLocale()`.
