Custom components are prefixed with `C` and auto-imported.

## Shell

| Component | Use |
|---|---|
| `CPage` | Page wrapper: `UDashboardPanel`, navbar with title and `#actions`, optional `#toolbar`, `wide` for full-width pages |
| `CSectionHeading` | Title + description + `#actions` for sections and card headers |
| `CStatTile` | Number tile with icon and hint |
| `CUserMenu`, `CLogo` | Sidebar footer and header |

## Forms & modals

| Component | Use |
|---|---|
| `CPriceInput` | Euro input with a cents model |
| `CDateInput` | `UInputDate` + calendar popover with a `'YYYY-MM-DD'` model |
| `CModalActions` | Cancel + submit row for modal forms |
| `CConfirmModal` | Opened by `useConfirm()` / `useAction({ confirm })` |
| `CTaskForm`, `CQuoteModal`, `CExpenseModal`, `CBudgetLineModal`, `CSubsidyModal`, `CContactModal`, `CCatalogModal`, `CInviteModal`, `CFloorPlanModal` | Entity forms; open them with `useOverlay().create(…)` and await `.result` |

## Feature components

| Component | Use |
|---|---|
| `CKanban`, `CTaskCard`, `CTaskMeta`, `CTaskList`, `CTaskSlideover` | Tasks |
| `CGantt` | Planning chart |

| `CDriveBrowser`, `CDrivePickerModal`, `CAttachments`, `CFileThumb` | Drive |

## Composables

| Composable | Returns |
|---|---|
| `useAction(fn, options)` / `useKeyedAction` | `{ run, pending }` with toast, confirm and error handling |
| `useLookups()` | Rooms, categories, phases, contacts, users as arrays, `Map`s by id and select options |
| `useTasks()` | All visible tasks, `byId`, `statusById`, `refresh` |
| `useDriveUpload()` | `{ upload(files, { folderId?, entityType?, entityId? }), uploading }` |
| `useNullableText(state, key)` | v-model for optional text that is `null` when empty |
| `useDashboardShortcuts()` | `g-t`, `g-p`, … keyboard shortcuts from `app/utils/nav.ts` |
| `useLogout()`, `useConfirm()`, `useApiError()`, `useZodLocale()` | Small helpers |

## Adding a screen

1. Add the page in `app/pages/`, wrap it in `CPage`, add `definePageMeta({ middleware: 'internal' })` if externals shouldn't see it.
2. Add it to `PRIMARY_NAV` or `SECONDARY_NAV` in `app/utils/nav.ts` (sidebar, bottom bar and ⌘K search follow).
3. Put the input schema in `shared/schemas/`, the response type in `shared/types/api.ts`, the endpoints in `server/api/`.
