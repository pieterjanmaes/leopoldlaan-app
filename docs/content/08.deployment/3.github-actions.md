| Workflow | Trigger | Wrangler env |
|---|---|---|
| `deploy-prod.yml` | push to `main` (and manual) | production |
| `deploy-preview.yml` | push to `preview` | `--env preview` |
| `deploy-preprod.yml` | push to `preprod` | `--env preprod` |
| `deploy-docs.yml` | changes under `docs/**` | this docs site |

Every app workflow: checkout → pnpm + Node 24 → `pnpm install` → `npx nuxt prepare` → **`npm test`** (a failing test stops the deploy) → `npm run build` with the [build-time variables](/deployment/environment-variables) → `npx wrangler deploy`.

Runtime secrets are **not** passed by GitHub; Cloudflare injects them at request time.

::warning
`deploy-preprod.yml` deploys with `--env preprod`, but `wrangler.jsonc` only defines `preview`. Either add a `preprod` environment (with its own D1 database) or remove the workflow before pushing a `preprod` branch.
::

## Repository settings

- **Secrets:** `CLOUDFLARE_API_TOKEN`
- **Variables:** `CLOUDFLARE_ACCOUNT_ID`, `NUXT_SITE_URL`, `NUXT_PUBLIC_TURNSTILE_SITE_KEY`, optionally `NUXT_PUBLIC_USERBACK_TOKEN`
- **Environments:** `production`, `preview` (and `preprod` if used), so values can differ per environment

## Pull requests

There's no CI on pull requests; the checks only run as part of a deploy. Run `pnpm run lint && pnpm run test` locally before merging to `main`.
