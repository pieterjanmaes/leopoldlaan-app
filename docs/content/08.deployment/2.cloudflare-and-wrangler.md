---
title: Cloudflare & Wrangler
description: One-time setup of the Worker, D1 databases and secrets.
---

The app runs as a Cloudflare Worker (`nitro.preset: 'cloudflare_module'` outside dev) with one D1 database per environment. `wrangler.jsonc` describes both.

## 1. Create the databases

```bash
npx wrangler login
npx wrangler d1 create leopoldlaan-app
npx wrangler d1 create leopoldlaan-app-preview
```

Paste each `database_id` into `wrangler.jsonc`, replacing `REPLACE_WITH_D1_ID` (top level for production, under `env.preview` for preview). The placeholders are deliberate: they stop a deploy from ever reaching the starter's databases.

## 2. Secrets

```bash
for name in NUXT_SESSION_PASSWORD NUXT_TURNSTILE_SECRET_KEY NUXT_OAUTH_GOOGLE_CLIENT_ID \
  NUXT_OAUTH_GOOGLE_CLIENT_SECRET NUXT_DRIVE_TOKEN_KEY SEED_KEY SEED_OWNER_EMAIL SEED_OWNER_PASSWORD; do
  npx wrangler secret put $name
done
```

Repeat with `--env preview` for the preview Worker. `keep_vars: true` keeps dashboard-set vars across deploys.

## 3. Google OAuth redirect

Add `https://<worker-or-domain>/auth/google-drive` to the authorized redirect URIs of the OAuth client ([Drive setup](/google-drive/setup)).

## 4. Deploy, migrate, seed

Deploy (via [GitHub Actions](/deployment/github-actions) or [manually](/deployment/deploying-manually)). NuxtHub applies pending migrations from `server/db/migrations/sqlite/` on startup. Then seed once:

```bash
curl -X POST -H "x-seed-key: $SEED_KEY" https://<domain>/api/seed
```

## Inspecting D1

```bash
npx wrangler d1 execute leopoldlaan-app --remote --command "SELECT name FROM _hub_migrations;"
npx wrangler d1 execute leopoldlaan-app --remote --command "SELECT title, status FROM tasks LIMIT 20;"
```

D1's **Time Travel** can restore a database to any minute in the last 30 days:

```bash
npx wrangler d1 time-travel info leopoldlaan-app
npx wrangler d1 time-travel restore leopoldlaan-app --timestamp=<unix-or-ISO>
```
