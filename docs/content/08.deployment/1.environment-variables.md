---
title: Environment variables
description: Every variable, what it's for and where it's set.
---

Locally everything lives in `.env` (copy from `.env.example`). Deployed, variables fall into three groups.

## A. Build-time, public

Baked into the client bundle during `nuxt build` — visible to anyone. Set as **GitHub Actions repository variables**.

| Variable | Purpose |
|---|---|
| `NUXT_SITE_ENV` | `production` or `staging` |
| `NUXT_SITE_URL` | Public URL of the app |
| `NUXT_PUBLIC_TURNSTILE_SITE_KEY` | Turnstile widget on the login page |
| `NUXT_PUBLIC_USERBACK_TOKEN` | Optional feedback widget |

## B. Runtime secrets

Read by the server at request time. Set as **Cloudflare Wrangler secrets** (`wrangler secret put NAME [--env preview]`).

| Variable | Purpose |
|---|---|
| `NUXT_SESSION_PASSWORD` | Encrypts the session cookie (32+ chars) |
| `NUXT_TURNSTILE_SECRET_KEY` | Verifies Turnstile tokens |
| `NUXT_OAUTH_GOOGLE_CLIENT_ID` | Google OAuth client for Drive |
| `NUXT_OAUTH_GOOGLE_CLIENT_SECRET` | Google OAuth client for Drive |
| `NUXT_DRIVE_TOKEN_KEY` | Encrypts the stored Drive refresh token (32+ chars). **Changing it makes the stored token unreadable** — reconnect Drive afterwards |
| `SEED_KEY` | Unlocks `POST /api/seed` outside development |
| `SEED_OWNER_EMAIL`, `SEED_OWNER_PASSWORD`, `SEED_OWNER_NAME` | Owner account created by the seed |
| `NUXT_OG_IMAGE_SECRET` | Starter leftover; unused while OG images are disabled |

## C. CI/CD only

| Variable | Where | Purpose |
|---|---|---|
| `CLOUDFLARE_API_TOKEN` | GitHub secret | `wrangler deploy` (Workers + D1 permissions) |
| `CLOUDFLARE_ACCOUNT_ID` | GitHub variable | Target account |
