---
title: Deploying manually
description: Build and deploy from your machine.
---

```bash
pnpm run build:deploy:preview      # loads .env.preview, builds, deploys --env preview
pnpm run build:deploy:production   # loads .env.production, builds, deploys
```

`.env.preview` / `.env.production` only need the **build-time** variables (site URL, Turnstile site key). Secrets stay in Cloudflare.

Deploy an existing build without rebuilding:

```bash
pnpm run deploy:preview
pnpm run deploy:production
```

## Smoke test after a deploy

- `/login` loads and the Turnstile widget appears
- logging in lands on the overview with numbers
- a task can be created and dragged on the board
- Instellingen → Google Drive shows *gekoppeld* (or connects), and Bestanden lists the project folder
- the floor plan shows its background image

Logs: `npx wrangler tail` (add `--env preview`), or the Worker's *Logs* tab — observability is enabled in `wrangler.jsonc`.
