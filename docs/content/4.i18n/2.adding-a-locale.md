---
title: Adding a new locale
description: Step-by-step to add a third (or fourth, fifth) language.
---

Say you want to add English alongside Dutch and French. Here's the full list of changes.

## 1. Add the locale to `nuxt.config.ts`

```ts
i18n: {
  locales: [
    { code: 'nl', language: 'nl-BE', name: 'Nederlands', file: 'nl.json' },
    { code: 'fr', language: 'fr-BE', name: 'Francais', file: 'fr.json' },
    { code: 'en', language: 'en-GB', name: 'English', file: 'en.json' } // NEW
  ],
  // ...
}
```

## 2. Add the translation file

Create `i18n/locales/en.json`. Copy the structure from `nl.json` and translate the values:

```json [i18n/locales/en.json]
{
  "error": {
    "pageNotFound": "Page not found"
  }
}
```

::warning
Every key in `nl.json` must exist in `en.json`. Missing keys log warnings and fall back to the key string itself.
::

## 3. Add a content collection

In `content.config.ts`:

```ts
collections: {
  content_nl: defineCollection({
    type: 'page',
    source: { include: 'nl/**/*.md', prefix: '/' },
    schema: pageSchema
  }),
  content_fr: defineCollection({
    type: 'page',
    source: { include: 'fr/**/*.md', prefix: '/' },
    schema: pageSchema
  }),
  content_en: defineCollection({ // NEW
    type: 'page',
    source: { include: 'en/**/*.md', prefix: '/' },
    schema: pageSchema
  })
}
```

## 4. Add content files

Mirror the existing structure:

```
content/
├── nl/
│   ├── index.md
│   ├── cookie-policy.md
│   └── ...
├── fr/
│   ├── index.md
│   ├── cookie-policy.md
│   └── ...
└── en/                # NEW
    ├── index.md       # canonicalId: home
    ├── cookie-policy.md  # canonicalId: cookie-policy
    └── ...
```

Use **matching `canonicalId`** values so the language switcher can link them. See [canonicalId](/content/canonical-ids).

## 5. Restart the dev server

Adding collections requires a fresh boot — HMR doesn't pick up `content.config.ts` changes:

```bash
rm -rf .nuxt
pnpm run dev
```

## 6. Verify

- Visit `https://localhost:3000/en` — should render `content/en/index.md`
- Click the language switcher in the header — should show the new locale option
- Switch to English from a Dutch page — should navigate to the equivalent EN page (matched by canonicalId)
- View page source — should include `<link rel="alternate" hreflang="en-GB" ...>` for any page with EN content

## What you don't need to change

The catch-all page (`app/pages/[...slug].vue`) builds the collection name from `locale.value` dynamically:

```ts
const collection = ('content_' + locale.value) as keyof Collections;
```

So adding a new collection named `content_en` is enough — no edits to the page needed.

The `useTranslatedPath` composable iterates `locales` automatically, so the language switcher picks up the new locale too.
