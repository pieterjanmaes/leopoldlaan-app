## Before the first deploy

- [ ] Create the D1 databases and replace `REPLACE_WITH_D1_ID` in `wrangler.jsonc` ([Cloudflare & Wrangler](/deployment/cloudflare-and-wrangler)).
- [ ] Set all Wrangler secrets for production and preview.
- [ ] Add a `preprod` environment to `wrangler.jsonc` or remove `deploy-preprod.yml` ([GitHub Actions](/deployment/github-actions)).
- [ ] Real Turnstile keys for the production domain.
- [ ] Seed once with `SEED_OWNER_*` set, log in, change the password.

## Google Drive

- [ ] Create the OAuth client, publish the consent screen to **In production** ([setup](/google-drive/setup)).
- [ ] Test the full flow end-to-end: connect, browse, upload, attach to a task, open as an external, set a floor plan background. *This is the one part that hasn't been tested against a real Google account yet.*

## Safety

- [ ] **Backups.** D1 Time Travel covers 30 days. For the budget data, add a periodic export (e.g. a weekly cron that writes a JSON or Excel dump into the Drive project folder).
- [ ] Keep `NUXT_DRIVE_TOKEN_KEY` somewhere safe — losing it means reconnecting Drive (no data loss, the files stay in Drive).
- [ ] Remove `'unsafe-eval'` from the CSP and retest ([CSP & headers](/security/csp-and-headers)).
- [ ] Optionally a Cloudflare WAF rate-limit rule on `/api/auth/*` ([Rate limiting](/security/rate-limiting)).

## Nice to have

- [ ] CI on pull requests (`pnpm run lint && pnpm run test`) so problems show up before merging.
- [ ] PDF backgrounds on the floor plan (render the first page to an image with `pdf.js`).
