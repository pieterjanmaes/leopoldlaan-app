---
title: CSP & headers
description: Security headers from nuxt-security and why each relaxation exists.
---

`nuxt-security` sets the headers; the config is under `security` in `nuxt.config.ts`.

```ts
contentSecurityPolicy: {
  'font-src': ["'self'", 'https:'],
  'img-src': ["'self'", 'data:', 'blob:', 'https:'],
  'script-src': ["'self'", "'unsafe-inline'", "'unsafe-eval'", '*.cloudflare.com'],
  'style-src': ["'self'", "'unsafe-inline'"],
  'connect-src': ["'self'", 'https:'],
  'media-src': ["'self'", 'https:'],
  'frame-src': ["'self'", '*.cloudflare.com', 'https://drive.google.com'],
  'object-src': ["'none'"],
  'base-uri': ["'self'"]
}
```

| Directive | Why |
|---|---|
| `script-src 'unsafe-inline'` | Nuxt's inline hydration payload |
| `script-src *.cloudflare.com`, `frame-src *.cloudflare.com` | The Turnstile widget on the login page |
| `img-src blob:` | Local previews of photos before upload |
| `frame-src drive.google.com` | Drive previews |
| `connect-src https:` | Room for third-party APIs; the app itself only calls its own origin |

Drive files are served **through the app** (`/api/drive/files/:id/content`), so file previews and the floor-plan background stay same-origin.

Other headers: HSTS for one year with `includeSubDomains` and `preload` (the domain isn't on the preload list until someone submits it), CORP `cross-origin` and COEP `unsafe-none` so fonts and the Turnstile iframe load.

## The app is private

`robots.disallow: ['/']` keeps search engines out, and every page except `/login` and `/registreer` requires a session. OG images are disabled (`ogImage.enabled: false`).

## Tightening later

`'unsafe-eval'` is a starter leftover; removing it is the first candidate. Test login (Turnstile), the floor plan (Konva) and Drive previews after any change.
