---
title: Canonical IDs (translation linking)
description: How content files in different locales are linked together for the language switcher and hreflang tags.
---

## Why canonicalId?

URLs in different locales rarely have matching slugs. The Dutch "cookie-policy" page might be called "politique-cookies" in French. To switch between them, you can't just swap the locale prefix — you need to look up the equivalent page.

`canonicalId` is a frontmatter field that links translations together:

```md [content/nl/cookie-policy.md]
---
canonicalId: cookie-policy
title: Cookieverklaring
---
```

```md [content/fr/politique-cookies.md]
---
canonicalId: cookie-policy
title: Déclaration relative aux cookies
---
```

Both files have `canonicalId: cookie-policy`. The language switcher and hreflang tags use this to find the right URL in the target locale.

## How it works

The composable `app/composables/useTranslatedPath.ts` queries each locale's collection by `canonicalId`:

```ts
const content = await queryCollection(collection)
  .where('canonicalId', '=', canonicalId)
  .first();
```

For each known locale, it returns the path stored under the matching canonicalId. Result:

```ts
{
  nl: '/cookie-policy',
  fr: '/politique-cookies'
}
```

The catch-all page (`app/pages/[...slug].vue`) calls `useTranslatedPath().getAllTranslatedPaths(page.canonicalId)` and stores the result in shared state. The language switcher reads that state and navigates to the right URL when you change locale.

## Choosing canonicalIds

Pick a short, stable identifier in **one** language (typically English or your default locale) and use it across all translations. They don't need to match filenames.

```yaml
canonicalId: home          # for index.md across all locales
canonicalId: cookie-policy # for the cookie/privacy page
canonicalId: contact       # for contact page even if FR uses /contactez-nous
```

If you change a canonicalId, change it in **every** locale's matching file or you'll break translation linking.

## Without canonicalId

The composable still works — it falls back to a literal slug swap (`/nl/about` → `/fr/about`). This works when filenames are identical across locales, but breaks the moment they diverge.

## hreflang tags

The catch-all page also emits `<link rel="alternate" hreflang="...">` tags built from the same translated paths, so search engines know which URL serves which locale:

```html
<link rel="alternate" hreflang="nl-BE" href="https://yoursite/nl/cookie-policy">
<link rel="alternate" hreflang="fr-BE" href="https://yoursite/fr/politique-cookies">
<link rel="alternate" hreflang="x-default" href="https://yoursite/nl/cookie-policy">
```

`x-default` points at the default locale's version.
