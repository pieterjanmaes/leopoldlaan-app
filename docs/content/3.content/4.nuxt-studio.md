## What is Studio?

[Nuxt Studio](https://nuxt.studio) is a visual editor for Nuxt Content. It loads your dev site in a preview panel, lets you edit markdown via a WYSIWYG UI on the right, and writes changes straight back to your local files.

It's invaluable for non-technical content editors and saves devs time when adjusting copy.

## Opening Studio in dev

1. Start the dev server: `pnpm run dev`
2. Open `https://localhost:3000/nl` in the browser
3. Click the floating **Studio button** in the top-left corner of the page
4. First time: sign in with GitHub at nuxt.studio

The button is rendered by the `<nuxt-studio>` custom element that the module mounts on the page. `app/assets/css/main.css` raises its `z-index` to 9999 so the sticky `<UHeader>` doesn't cover it.

## Studio config in `nuxt.config.ts`

```ts
studio: {
  i18n: { defaultLocale: 'nl' }
}
```

`studio.i18n.defaultLocale` tells Studio which locale's collection to show by default in the sidebar. The repository is auto-detected from `git config remote.origin.url` — no need to set `studio.repository` for local dev.

## What you can edit

- **Page frontmatter** — title, description, canonicalId, schema-defined fields
- **Markdown body** — paragraphs, headings, lists, links, images
- **MDC components** — Studio understands `::u-page-hero`, `::u-page-section`, etc. and provides forms for their props (as long as you use [YAML syntax](/content/markdown-and-mdc))

Changes save instantly to disk; Nuxt Content rebuilds the affected collection and the preview reloads.

## What you CANNOT edit

- Code components (anything in `app/components/`) — Studio is for content, not Vue
- File structure (add/delete files) — do that on the filesystem
- The Vue templates that wrap content (layouts, the catch-all page)

## If Studio's sidebar is empty

The most common cause is the `cloudflare_module` preset being active in dev — see [Nitro preset & Content](/troubleshooting/nitro-preset-and-content). The fix is the conditional preset in `nuxt.config.ts`:

```ts
nitro: {
  preset: process.env.NODE_ENV === 'development' ? undefined : 'cloudflare_module'
}
```

## Production / self-hosted Studio

The dev flow above uses Studio's hosted cloud editor. For production deployments where you want non-devs to edit live content:

1. Register a GitHub OAuth App
2. Set `STUDIO_GITHUB_CLIENT_ID` and `STUDIO_GITHUB_CLIENT_SECRET` env vars
3. Configure `studio.repository` explicitly in `nuxt.config.ts`

See the [Nuxt Studio docs](https://nuxt.studio/setup) for the full setup.
