## The seed endpoint

`server/api/seed.post.ts` creates the seed data — currently a single superadmin user.

```bash
curl -k -X POST https://localhost:3000/api/seed
```

Output:

```json
{ "success": true, "user": { "id": "...", "email": "..." } }
```

The default credentials are defined in `seed.post.ts` — check the file to see the current email/password.

## After seeding

1. Go to `https://localhost:3000/nl/dashboard/login`
2. Sign in with the seed email/password
3. You'll land on `/dashboard` with full superadmin rights

From here you can create more users via `/dashboard/users` (superadmin-only UI).

## When the endpoint is gated

In production, you probably don't want `/api/seed` exposed unauthenticated. The endpoint checks for the `SEED_KEY` env var in non-dev environments:

| Environment | Behavior |
|---|---|
| dev (`NODE_ENV !== 'production'`) | Open — anyone can hit it |
| Other | Requires `?key=<value>` matching `process.env.SEED_KEY` |

Set `SEED_KEY` via `wrangler secret put SEED_KEY` (see [Environment variables](/deployment/environment-variables)) and call:

```bash
curl -X POST "https://your-deploy/api/seed?key=<your-seed-key>"
```

## Adding more seed data

Edit `server/api/seed.post.ts` to insert additional rows. Use the Drizzle client just like in any other server route:

```ts
import { db } from 'hub:db';
import { users, formSubmissions } from '~~/server/db/schema';
import { hashPassword } from '#auth-utils';

export default defineEventHandler(async () => {
  await db.insert(users).values({
    email: 'admin@wotz.be',
    password: await hashPassword('change-me'),
    name: 'Admin',
    role: 'superadmin'
  }).onConflictDoNothing();

  // Add more seed inserts here

  return { success: true };
});
```

`onConflictDoNothing()` makes the seed safely re-runnable — won't fail if the row already exists.

## Resetting

To start completely fresh:

```bash
rm -f .data/db/sqlite.db .data/db/sqlite.db-shm .data/db/sqlite.db-wal
pnpm run dev   # recreates DB + applies migrations
curl -k -X POST https://localhost:3000/api/seed
```
