## Stack

- **ORM**: [Drizzle ORM](https://orm.drizzle.team) — type-safe SQL builder
- **Local DB**: libsql / better-sqlite3 file at `.data/db/sqlite.db` (managed by `@nuxthub/core`)
- **Production DB**: Cloudflare D1 (via the `DB` binding in `wrangler.jsonc`)
- **IDs**: [CUID2](https://github.com/paralleldrive/cuid2) — collision-resistant, sortable, URL-safe

## Schema definition

`server/db/schema.ts` defines the tables:

```ts
import { createId } from '@paralleldrive/cuid2';
import { sqliteTable, text, integer } from 'drizzle-orm/sqlite-core';

export const users = sqliteTable('users', {
  id: text('id').primaryKey().$defaultFn(() => createId()),
  email: text('email').notNull().unique(),
  password: text('password').notNull(),
  name: text('name'),
  role: text('role', { enum: ['admin', 'superadmin'] }).notNull().default('admin'),
  createdAt: integer('created_at', { mode: 'timestamp' }).$defaultFn(() => new Date())
});

export const formSubmissions = sqliteTable('form_submissions', {
  id: text('id').primaryKey().$defaultFn(() => createId()),
  firstName: text('first_name').notNull(),
  lastName: text('last_name').notNull(),
  email: text('email').notNull(),
  phone: text('phone'),
  timeSlot: text('time_slot'),
  createdAt: integer('created_at', { mode: 'timestamp' }).$defaultFn(() => new Date())
});
```

Conventions:
- **Primary key is always `text` with CUID2** — never `integer AUTOINCREMENT`. Avoids ID collisions, supports inserts from API without round-tripping.
- **Timestamps stored as `integer` with `mode: 'timestamp'`** — Drizzle converts to/from `Date` automatically.
- **Enums on text columns** via `text('col', { enum: [...] })` for type safety.

## Accessing the DB from server routes

Use the `hub:db` virtual module provided by `@nuxthub/core`:

```ts [server/api/users/index.get.ts]
import { db } from 'hub:db';
import { users } from '~~/server/db/schema';

export default defineEventHandler(async () => {
  return await db.select().from(users);
});
```

The `~~/` alias resolves to the project root, so `~~/server/db/schema` is reliable from anywhere in the codebase.

## Insert/update with type safety

Drizzle infers types from the schema:

```ts
const submission = await db.insert(formSubmissions).values({
  firstName: body.firstName,
  lastName: body.lastName,
  email: body.email,
  phone: body.phone,
  timeSlot: body.timeSlot
}).returning().get();
// submission.id is auto-generated by $defaultFn(createId())
// submission.createdAt is auto-set to new Date()
```

`returning().get()` returns the inserted row (with the generated `id` and `createdAt` filled in).

## Adding a new table

1. Edit `server/db/schema.ts` to add the new `sqliteTable(...)` definition
2. Generate a migration: `pnpm run db:generate`
3. Verify the new SQL file in `server/db/migrations/sqlite/`
4. Restart `pnpm run dev` — `@nuxthub/core` runs pending migrations on boot

See [Migrations](/database/migrations) for the full migration workflow.
