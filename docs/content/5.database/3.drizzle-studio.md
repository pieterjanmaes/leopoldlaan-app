title: Drizzle Studio
description: Browse and edit the local dev database in a web UI.
---

## Open the UI

```bash
pnpm run db:studio
```

The terminal prints `Drizzle Studio is up and running on https://local.drizzle.studio`. Open that URL — it connects via a local proxy to your dev database (`.data/db/sqlite.db`).

You'll see:
- **Tables sidebar** — `users`, `form_submissions`, `_hub_migrations`
- **Data view** — click a table to browse, filter, sort rows
- **Inline editing** — double-click a cell to edit, hit save
- **Schema view** — see column types, foreign keys, indexes

## Configuration

`drizzle.config.ts` tells Drizzle Studio where the DB lives:

```ts
import { defineConfig } from 'drizzle-kit';

export default defineConfig({
  dialect: 'sqlite',
  schema: './server/db/schema.ts',
  out: './server/db/migrations/sqlite',
  dbCredentials: {
    url: 'file:.data/db/sqlite.db'
  }
});
```

The `file:` prefix tells drizzle-kit to use the file driver (libsql/better-sqlite3).

## Caveats

::warning
**SQLite is single-writer.** Don't run `pnpm run dev` and `pnpm run db:studio` writes at the same time — you'll hit `SQLITE_BUSY`. Read-only browsing is fine.
::

::warning
**Don't alter schema through Studio.** Studio happily lets you ADD/DROP columns inline, but those changes won't be reflected in `server/db/schema.ts` or in a generated migration. Always go through `pnpm run db:generate`.
::

::warning
**Local dev only.** This config points at `.data/db/sqlite.db`. To inspect production D1, use the **Cloudflare dashboard's D1 console** at `dash.cloudflare.com → Workers & Pages → D1 → your database → Console`.
::

## What's useful for

- Quickly check what came through from a form submission
- Verify your seed worked
- Reset a stuck user (e.g. flip a `role` from `admin` to `superadmin`)
- Debug why a query returns the wrong data — see actual rows side-by-side
- Inspect what migrations have been applied (`_hub_migrations` table)

## What's NOT useful for

- Schema changes (use migrations)
- Bulk data import (write a script that uses the Drizzle client)
- Production data (use D1 console)
