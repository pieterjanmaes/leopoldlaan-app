---

`/planning` (`app/pages/planning.vue`, `app/components/CGantt.vue`).

- **Rows** are grouped by **phase**; a grey bar shows the phase's own start and end. Tasks without a phase go under *Zonder fase*.
- **Bars** run from start date to deadline (one of the two is enough) and take the **werkpost colour**. Done tasks are faded.
- **Milestones** (phases marked as milestone) are diamonds with a dashed vertical line; the red line is today.
- **Header** shows months and ISO week numbers. Four zoom levels (3–24 px per day) are remembered per browser.
- **Warnings** — a task that starts before a task it waits on ends gets a red outline, and an alert above the chart counts them.
- Below the chart, **Nog niet ingepland** lists open tasks without dates.

Clicking a bar or row opens the task panel. The chart is a plain Tailwind/HTML grid (no chart library); dates are `YYYY-MM-DD` strings and all arithmetic uses UTC day numbers (`shared/utils/dates.ts`), so daylight-saving changes never add or drop a day.
