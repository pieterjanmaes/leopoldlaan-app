`/` (`app/pages/index.vue`, data from `GET /api/dashboard`).

| Block | Contents |
|---|---|
| **Stat tiles** | Open tasks (with in progress / waiting), % done, expected cost vs budget, amount still to pay |
| **Deze week** | Tasks in progress, or planned to overlap the current Monday–Sunday |
| **Aandacht nodig** | Overdue tasks, and tasks that wait on an unfinished task and start within 14 days |
| **Budget per werkpost** | The same bars as on the budget page |
| **Recente bestanden** | The latest Drive files attached anywhere |

"Today" and the week are computed in the `Europe/Brussels` timezone on the server, so the overview doesn't shift when a Worker runs in another region.

Externals see the task blocks for their own tasks only; the budget tiles and bars are left out (`budget: null` in the API response).
