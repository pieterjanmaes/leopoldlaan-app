`/taken` (`app/pages/taken.vue`).

## Board and list

- **Bord** — four columns (*Te doen*, *Bezig*, *Wacht*, *Klaar*). Drag a card to change its status or order; on touch screens press and hold for 200 ms so scrolling the board doesn't start a drag. Built on `sortablejs` in `CKanban.vue`; a drop calls `POST /api/tasks/move` with the column's new order, and the UI updates optimistically.
- **Lijst** — a `UTable` with a checkbox to mark tasks done.
- **Filters** — search, werkpost, ruimte, fase, and *Verberg klaar*. The chosen view and toggle are remembered per browser.
- **Snel toevoegen** — type a title and press Enter; the active filters are used as defaults.

## Task fields

Title, description, status, priority, werkpost (category), ruimte (room), fase (phase), *Wie* (a housemate **or** a contact), start date, deadline and **Wacht op** (dependencies).

`doneAt` is set when the status becomes *Klaar* and cleared when it leaves it.

## Dependencies

"Plasterwork waits on electricity" is stored in `task_dependencies`. The server refuses edges that would create a loop (`wouldCreateCycle` in `shared/utils/dependencies.ts`). A task whose predecessor isn't done shows *wacht op andere taak*; the planning flags tasks that are scheduled to start before their predecessor ends.

## Detail panel

Clicking a task opens `CTaskSlideover`. Its id is kept in the URL (`/taken?taak=…`), so the overview and the search palette (⌘K) link straight to it. The panel holds the edit form, attachments (upload, phone camera, or pick from Drive) and comments.

Externals get a read-only view with only a status selector, plus attachments and comments.
