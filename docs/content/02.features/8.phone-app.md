The app is an installable **Progressive Web App**: it gets an icon on the home screen, opens full-screen without browser bars, and has shortcuts on a long press of the icon.

## Installing

| Device | How |
|---|---|
| **Android / Chrome / Edge** | Account menu (bottom of the sidebar) → **Installeer als app**, or the card on **Mijn account**. The browser shows its own install dialog |
| **iPhone / iPad (Safari)** | The same menu item opens a short guide: *Deel* → *Zet op beginscherm* → *Voeg toe* |
| **Desktop Chrome / Edge** | Same menu item, or the install icon in the address bar |

The menu item only appears when installing is possible and the app isn't already running installed.

## Home-screen shortcuts

Long-press the icon (Android) for **Nieuwe taak** (opens the new-task form), **Taken**, **Grondplan** and **Budget**. They're defined in `public/manifest.webmanifest`.

## How it's built

- `public/manifest.webmanifest` — name, colours, `display: standalone`, icons, shortcuts.
- `public/icons/` — 192 px and 512 px icons, a 512 px **maskable** icon (extra safe zone for Android's round or squircle masks), a 180 px `apple-touch-icon`, a 32 px favicon and an SVG. They're rendered from the Lucide *house-plus* glyph on the amber brand square with `@resvg/resvg-js`.
- `nuxt.config.ts → app.head` — manifest and icon links, `theme-color` for light and dark, Apple web-app meta tags, and a tiny inline script that catches Chrome's `beforeinstallprompt` event. That event fires once, often before Nuxt has booted, so the script parks it on `window` for `usePwaInstall()`.
- `usePwaInstall()` / `useInstallApp()` — detect standalone mode and iOS, show the browser's install dialog or the iOS guide (`CInstallAppModal`).

## No service worker, on purpose

Chrome no longer requires a service worker to install an app, and leaving it out means pages and data are never served stale from a cache — important when two people and a contractor edit the same tasks. The trade-off: the app needs a connection. Offline support (for example a queue of photos taken in a basement without signal) can be added later with `@vite-pwa/nuxt`.

## Testing installability

Chrome only offers installation after the user clicked the page once and spent 30 seconds on the site, and never in incognito windows (including isolated automation contexts). In DevTools → **Application → Manifest** you can check the manifest and icons, and trigger installation manually.
