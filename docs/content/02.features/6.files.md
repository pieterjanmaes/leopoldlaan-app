`/bestanden` (`app/components/CDriveBrowser.vue`). Household only.

- Browse the project folder and its subfolders (breadcrumbs, grid or list view).
- **Upload** with the button or by dragging files onto the page; **Map** creates a folder.
- Images and PDFs open in a preview modal with *Open in Drive* and *Download*; other files open in Drive.

## Attachments

`CAttachments` appears on tasks, quotes and invoices. It can upload (including the phone camera via `capture="environment"`), pick existing files from Drive (`CDrivePickerModal`) or unlink a file. Unlinking only removes the link (`attachments` row); the file stays in Drive.

Externals can upload photos to their own tasks. They can't browse, so their uploads land in a fixed folder *Uploads van externen* in the project folder.

See [How it works](/google-drive/how-it-works) for the server side and access checks.
