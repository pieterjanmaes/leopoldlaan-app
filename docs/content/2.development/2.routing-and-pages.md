## File-based routing

`app/pages/` follows the standard Nuxt convention. The notable files:

| File | URL |
|---|---|
| `app/pages/[...slug].vue` | Catch-all for everything else — renders Nuxt Content pages |
| `app/pages/dashboard/index.vue` | `/dashboard` — form submissions list |
| `app/pages/dashboard/login.vue` | `/dashboard/login` |
| `app/pages/dashboard/users.vue` | `/dashboard/users` — superadmin only |

i18n adds locale prefixes automatically (`/nl/...`, `/fr/...`). Root `/` → 302 → `/nl`.

## The catch-all (`[...slug].vue`)

This page renders any URL that isn't explicitly defined elsewhere by looking up matching markdown in Nuxt Content.

```vue
<template>
  <ContentRenderer v-if="page" :value="page" :data="page" />
</template>

<script setup lang="ts">
const route = useRoute();
const { locale, locales, t } = useI18n();
const { getAllTranslatedPaths } = useTranslatedPath();

const slug = computed(() => {
  const slugParam = route.params.slug;
  const slugPath = Array.isArray(slugParam) ? slugParam.join('/') : slugParam;
  return withLeadingSlash(slugPath || '');
});

const { data: page } = await useAsyncData(
  `page-${locale.value}-${slug.value}`,
  async () => {
    const collection = ('content_' + locale.value) as keyof Collections;
    return await queryCollection(collection).path(slug.value).first();
  },
  { watch: [locale, slug] }
);
</script>
```

Key points:
- **The collection is locale-scoped** (`content_nl` vs `content_fr`) — see [Collections](/content/collections)
- **The query path is locale-agnostic** (`/about`, not `/nl/about`) — see [Collections](/content/collections)
- **Both `:value` and `:data` are passed** to `<ContentRenderer>` — required for Nuxt Studio's edit-by-click detection
- **`watch: [locale, slug]`** triggers a refetch when the language switcher fires

## Layouts

Three layouts in `app/layouts/`:

| Layout | Used by |
|---|---|
| `default` | Public site pages (catch-all + any future top-level pages) |
| `dashboard` | `/dashboard/**` admin pages (sidebar nav + auth-protected) |
| `login` | `/dashboard/login` (full-bleed centered) |

Pages opt in with `definePageMeta`:

```ts
definePageMeta({
  layout: 'dashboard',
  middleware: 'auth'
});
```

## Middleware

- **`auth.ts`** — redirects unauthenticated users to `/dashboard/login`
- **`superadmin.ts`** — redirects non-superadmin users to `/dashboard`

Apply via `definePageMeta({ middleware: 'auth' })` or `'superadmin'`.

## Root redirect

`/` does not render a page directly — `nuxt.config.ts` configures i18n to redirect to the default locale:

```ts
i18n: {
  rootRedirect: { path: 'nl', statusCode: 302 }
}
```

If you want `/` to land somewhere else (e.g. a non-localized splash page), remove `rootRedirect` and either create `app/pages/index.vue` or change the i18n strategy.
