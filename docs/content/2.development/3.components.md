## Conventions

- **`<script setup lang="ts">`** + Composition API everywhere
- **Custom components are prefixed `C`** to distinguish them from Nuxt UI components (`U*`). Examples: `CHeader`, `CFooter`, `CForm`, `CLanguageSwitcher`, `CLogo`
- Components are **auto-imported** from `app/components/` — no manual `import` statements

## Nuxt UI v4

The project uses [Nuxt UI](https://ui.nuxt.com) v4. All `U*` components are globally available and don't need importing. Theme customization (primary color, etc.) lives in `app/app.config.ts`.

```vue
<UButton color="primary" size="lg" to="/dashboard">
  Sign in
</UButton>
```

## MDC (Markdown Components) — the YAML rule

Inside markdown content files, you can embed Vue components via MDC syntax. **Always use YAML frontmatter syntax for props, not inline attributes.**

::tip
The Vite parser sometimes mishandles inline-attribute MDC syntax, and Studio's WYSIWYG editor only round-trips YAML props cleanly. YAML is the safe default.
::

### Correct

```md
::u-alert
---
icon: i-lucide-triangle-alert
color: warning
title: Let op
description: Dit is voorbeeldinhoud.
---
::
```

### Avoid

```md
::u-alert{icon="i-lucide-triangle-alert" color="warning" title="Let op"}
::
```

## MDC component naming

Inside markdown, components are kebab-cased with the `u-` prefix:

| Vue component | MDC syntax |
|---|---|
| `<UPageHero>` | `::u-page-hero` |
| `<UPageSection>` | `::u-page-section` |
| `<UCard>` | `:::u-card` |
| `<UButton>` | `:u-button` |
| `<CPlaceholder>` | `:c-placeholder` |

The colon count indicates nesting depth:
- `:component` — inline (no children)
- `::component` — block (single-level nesting)
- `:::component` — one level deeper
- `::::component` — two levels deeper

## Custom logo icon collection

`app/assets/svg/logos/*.svg` is exposed as a custom Iconify collection with prefix `logo:`. Use any SVG in the folder:

```vue
<UIcon name="logo:google" />
```

Configured in `nuxt.config.ts`:

```ts
icon: {
  customCollections: [
    { prefix: 'logo', dir: './app/assets/svg/logos', normalizeIconName: true }
  ]
}
```

## Styling

- Primary stylesheet: `app/assets/css/main.css` (imports Tailwind + Nuxt UI)
- Prose styles for `<ContentRenderer>` output: `app/assets/css/prose.css`
- Brand color: violet (`--color-violet-500: #802eaf`) — set in `main.css` and referenced by Nuxt UI theme via `app.config.ts`
