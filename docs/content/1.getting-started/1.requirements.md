## Node.js 22+

The project requires Node.js **22.0.0 or newer**. Check your version:

```bash
node --version
# v22.x or higher
```

If you're on an older version, install [nvm](https://github.com/nvm-sh/nvm) and run `nvm install 22 && nvm use 22`.

## pnpm

The project uses **pnpm** as its package manager — npm and yarn won't work because the lockfile is `pnpm-lock.yaml`. The required version is pinned in `package.json` under `"packageManager"`.

```bash
# Install pnpm globally
npm install -g pnpm

# Verify
pnpm --version
```

## mkcert (for local HTTPS)

The dev server runs on **HTTPS** at `https://localhost:3000` because Nuxt Studio and Cloudflare Turnstile both require a secure context. You need locally-trusted certificates.

[mkcert](https://www.npmjs.com/package/mkcert) generates them in seconds:

```bash
# Install the local CA (one-time per machine)
npx mkcert create-ca

# Generate the localhost cert
npx mkcert create-cert --domains localhost
```

This creates `ca.crt`, `ca.key`, `cert.crt`, `cert.key`. Rename the cert pair to match what `nuxt.config.ts` expects:

```bash
mv cert.crt localhost.pem
mv cert.key localhost-key.pem
```

The `.pem` files are gitignored and stay on your machine. The CA only needs to be installed once per machine; new projects reuse it with `npx mkcert create-cert` alone.

## A Cloudflare account (for deploys only)

You don't need a Cloudflare account to develop locally — only when you start deploying. See [Cloudflare & Wrangler](/deployment/cloudflare-and-wrangler) for setup.
