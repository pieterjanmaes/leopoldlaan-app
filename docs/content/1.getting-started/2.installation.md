## Clone the repository

```bash
git clone git@github.com:wotzebra/wotz-nuxt-starter.git
cd wotz-nuxt-starter
```

## Install dependencies

```bash
pnpm install
```

The project has `shamefully-hoist=true` in `.npmrc`, so pnpm produces a flat-ish `node_modules`. The `postinstall` script runs `nuxt prepare` to generate types and the `.nuxt` build directory.

## Set up environment variables

Copy the example file and fill in any blanks:

```bash
cp .env.example .env
```

The defaults work for local development (test Turnstile keys, localhost URL). The only thing you usually need to set is `NUXT_SESSION_PASSWORD` — generate one with:

```bash
openssl rand -hex 32
```

For full details on what each variable means and where it should live in production, see [Environment variables](/deployment/environment-variables).

## Verify the install

```bash
pnpm run lint
```

Should report `Found 0 warnings and 0 errors.` If the lint fails on a fresh clone, that's a regression worth fixing or reporting before you start work.
