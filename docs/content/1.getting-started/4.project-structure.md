## Top-level layout

```
.
├── app/                          # Nuxt 4 source root (NOT src/)
├── content/                      # Markdown content (per-locale folders)
├── i18n/                         # i18n config + translation JSON files
├── server/                       # Server-only code (API routes, DB)
├── public/                       # Static assets served at /
├── .github/workflows/            # Deploy workflows
├── docs/                         # This documentation site
├── nuxt.config.ts                # Main Nuxt config
├── content.config.ts             # Nuxt Content collections
├── drizzle.config.ts             # Drizzle ORM config
├── oxlint.config.ts              # Oxlint config (shared @wotzebra/oxc-config)
├── oxfmt.config.ts               # Oxfmt config (shared @wotzebra/oxc-config)
├── eslint.config.mjs             # ESLint (Vue stylistic rules only)
└── wrangler.jsonc                # Cloudflare Worker config (gitignored)
```

## `app/` — Nuxt source

```
app/
├── assets/
│   ├── css/           # main.css (Tailwind + Studio z-index override) + prose.css
│   └── svg/logos/     # Custom logo icon collection (prefix: logo:)
├── components/        # Vue components — custom ones use the C-prefix
├── composables/       # Auto-imported composables (useTranslatedPath, etc.)
├── layouts/           # default, dashboard, login
├── middleware/        # auth, superadmin (route guards)
├── pages/             # File-based routing
│   ├── [...slug].vue  # Catch-all that renders Nuxt Content pages
│   └── dashboard/     # Admin UI (form submissions, users)
└── plugins/           # cookieFirst, userback, scrollBehavior
```

## `content/` — Markdown content

```
content/
├── nl/                # Dutch pages — content path = file path WITHOUT /nl prefix
│   ├── index.md
│   ├── cookie-policy.md
│   └── privacy-policy.md
└── fr/                # French equivalents (matched via canonicalId)
    ├── index.md
    ├── cookie-policy.md
    └── privacy-policy.md
```

See [Content collections](/content/collections) for the configuration details and why paths look the way they do.

## `server/` — Backend

```
server/
├── api/               # API endpoints (auth, users, form, seed)
├── db/
│   ├── schema.ts      # Drizzle table definitions
│   ├── migrations/
│   │   └── sqlite/    # Drizzle-generated migration files (DO NOT hand-edit)
│   └── seed.ts        # Seed data
└── utils/             # Server helpers (drizzle instance, etc.)
```

DB access uses `import { db } from 'hub:db'` — the `hub:` virtual module provided by `@nuxthub/core`.

## What you DON'T touch

- `.nuxt/` — generated on `pnpm run dev` / `prepare`; safe to delete and regenerate
- `.data/` — local dev databases (content + app); wipe to reset
- `.wrangler/` — Cloudflare D1 emulator state when using the cloudflare nitro preset
- `node_modules/`, `.output/` — generated
