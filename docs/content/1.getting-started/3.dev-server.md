## Start the dev server

```bash
pnpm run dev
```

The server boots on **`https://localhost:3000`**. The `/` route 302-redirects to `/nl` (the default locale).

::note
First boot will run pending Drizzle migrations against the local SQLite DB (`.data/db/sqlite.db`). If you don't see a "migrations applied" log, the DB was already up-to-date.
::

## Common dev commands

```bash
pnpm run dev          # HTTPS dev server on :3000
pnpm run lint         # Run oxlint + eslint
pnpm run lint:fix     # Auto-fix
pnpm run format       # Run oxfmt
pnpm run format:check # Check formatting without writing
pnpm run test         # Run Vitest (unit + nuxt)
pnpm run test:watch   # Vitest in watch mode
pnpm run db:generate  # Generate a new Drizzle migration after schema edits
pnpm run db:studio    # Open Drizzle Studio in the browser
```

## Seed an admin user

The first time you run the project, the `users` table is empty so you can't log into `/dashboard`. Hit the seed endpoint to create a superadmin:

```bash
curl -k -X POST https://localhost:3000/api/seed
```

The `-k` flag tells curl to ignore the self-signed cert. Check `server/api/seed.post.ts` for the default email/password.

## Common boot-time messages

::callout{icon="i-lucide-info"}
**`[nuxt-site-config] WARN url "https://localhost:3000" from buildEnv should not be localhost`**
Harmless — the SEO module dislikes localhost as a canonical URL. Only matters in deployed environments.
::

::callout{icon="i-lucide-info"}
**`Vite discovered new dependencies at runtime`**
Vite found a dep it wasn't expecting and is reloading the page to pre-bundle it. If it keeps happening for the same package, add the name to `vite.optimizeDeps.include` in `nuxt.config.ts`. See [Vite dependency duplication](/troubleshooting/vite-dep-duplication).
::

## If something goes wrong

See [Troubleshooting](/troubleshooting/nitro-preset-and-content) — the most common dev-time issues (empty Studio sidebar, blank page after switching locale, datatype mismatch in migrations) all have known root causes documented there.
