---
title: Nuxt Studio sidebar is empty
description: Things to check when Studio opens but shows no collections / files.
---

## First: check the Nitro preset

The #1 cause is documented separately because it also breaks the public site: see [Nitro preset & Content](/troubleshooting/nitro-preset-and-content). If you haven't applied the conditional preset fix, do that first.

The rest of this page covers other possible causes.

## Studio button isn't visible

If the floating button isn't where you expect (upper-left corner):

- It might be **hidden behind `<UHeader>`** — `app/assets/css/main.css` should have:
  ```css
  nuxt-studio {
    position: relative;
    z-index: 9999;
  }
  ```
- It might be **not mounted at all** — check the browser console for any error during the dev plugin's load
- Try `document.querySelector('nuxt-studio')` in the console — if `null`, the plugin failed to run

## Studio mounted but sidebar is empty

If you can see Studio's UI but the sidebar shows no collections/files:

### Check that collections are registered

```bash
cat .nuxt/content/preview.mjs | grep '"name":'
```

Should list both `content_nl` and `content_fr`. If only one, check `content.config.ts`.

### Check the sql_dump endpoint returns data

```bash
curl -ks -o /dev/null -w "size: %{size_download}\n" \
  "https://localhost:3000/__nuxt_content/content_nl/sql_dump.txt"
```

Should be `> 0`. If `0`, you're hitting the Nitro preset bug.

### Run Studio's diagnostic

In the browser console while Studio is open:

```js
({
  collections: window.useStudioHost?.()?.collection?.list?.()?.map(c => c.name),
  dev: window.__NUXT__?.config?.public?.studio?.dev,
  hasContent: !!window.useNuxtApp?.()?.$content
})
```

Expected output:
```js
{
  collections: ['content_nl', 'content_fr'],
  dev: true,
  hasContent: true
}
```

If `dev: false`, runtime config didn't load Studio in dev mode (check the modules list).
If `collections: []`, the collection filter dropped them — check the source config has no `_custom` or `repository` flags.
If `hasContent: false`, `@nuxt/content` failed to register — check the module list and the boot log.

## Studio opens but the preview is blank

Different issue from the sidebar being empty. The preview is just an iframe rendering your local site. If it's blank:

- Check that `https://localhost:3000/nl` renders fine directly (in a separate tab)
- Check the `frame-ancestors` CSP directive in `nuxt.config.ts` — if you've explicitly set it, must include `'self'`
- `nuxt-security` defaults to `xFrameOptions: 'SAMEORIGIN'` which works for same-origin Studio embedding

## Studio's edit button on a content section does nothing

The catch-all page must pass `:data="page"` (not just `:value="page"`) to `<ContentRenderer>` so Studio knows the source path:

```vue
<ContentRenderer v-if="page" :value="page" :data="page" />
```

Without `:data`, Studio's "edit this section" detection doesn't fire.

## When all else fails

Nuke caches and restart:

```bash
rm -rf .nuxt node_modules/.cache .wrangler
pnpm run dev
```

Then in the browser: DevTools → Application → Storage → Clear site data → hard refresh.
