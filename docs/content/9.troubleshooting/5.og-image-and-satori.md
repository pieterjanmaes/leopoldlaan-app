---
title: OG image / satori version errors
description: Why satori is pinned and what the @nuxt/fonts warning during build means.
---

## Symptoms

`pnpm run build` fails with:

```
ERROR  [Nuxt OG Image] Satori 0.36.0 is not supported. Satori 0.47.1 or later is required.
```

Or, with an older `nuxt-og-image` and a newer `satori`:

```
Cannot resolve ".../satori/yoga.wasm?module" ... externals are not allowed
```

## Cause

`nuxt-og-image` ships as part of `@nuxtjs/seo` and supports only a narrow range of `satori` versions, declared as a peer dependency. Our direct `satori` devDependency is the copy that gets hoisted, so it must fall inside that range:

| `@nuxtjs/seo` | `nuxt-og-image` | `satori` |
|---|---|---|
| 5.x | ≤ 6.10.3 | `^0.36.0` (expects `yoga.wasm`, renamed to `layout.wasm` in 0.37) |
| 6.x | 7.x | `^0.47.1` |

`satori@latest` is usually **outside** that range. Running `pnpm update --latest` on everything will break the build.

## Fix

When bumping `@nuxtjs/seo`, check which `satori` the new `nuxt-og-image` wants, and move `satori` with it:

```bash
pnpm why nuxt-og-image                                  # which version is installed
pnpm view nuxt-og-image@<version> peerDependencies       # look for "satori"
pnpm add -D satori@<range from peerDependencies>
pnpm run build                                           # verify
```

When updating everything at once, leave `satori` out and handle it separately:

```bash
pnpm update --latest '!satori'
```

## `@nuxt/fonts 0.14.0 is not supported`

The build also logs:

```
[@nuxtjs/og-image]  ERROR  @nuxt/fonts 0.14.0 is not supported. Version 1.0.0+ is required for OG image font extraction.
```

This **does not fail the build**. `@nuxt/fonts` 0.14 comes in through `@nuxt/ui`, so it can't be bumped independently — adding `@nuxt/fonts@1` directly would just put two copies in the tree. It only disables custom-font extraction for generated OG images, and this starter doesn't generate any (no `defineOgImage` calls). It goes away once `@nuxt/ui` moves to `@nuxt/fonts@1`.
