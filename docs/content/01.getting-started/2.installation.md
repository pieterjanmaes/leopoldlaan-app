## 1. Install

```bash
pnpm install
cp .env.example .env
```

## 2. Fill in `.env`

The minimum for local development:

| Variable | Value |
|---|---|
| `NUXT_SESSION_PASSWORD` | 32+ random characters (`openssl rand -base64 32`) |
| `NUXT_PUBLIC_TURNSTILE_SITE_KEY` / `NUXT_TURNSTILE_SECRET_KEY` | Keep the Cloudflare test keys from `.env.example` |
| `NUXT_DRIVE_TOKEN_KEY` | 32+ random characters; only used once Drive is connected |

Google Drive needs two more (`NUXT_OAUTH_GOOGLE_CLIENT_ID` / `_SECRET`), see [Google Drive setup](/google-drive/setup). The full list is in [Environment variables](/deployment/environment-variables).

## 3. Start the dev server

```bash
pnpm run dev
```

On start, `@nuxthub/core` creates the local SQLite database in `.data/db/sqlite.db` and applies every migration from `server/db/migrations/sqlite/`.

## 4. Seed

```bash
curl -k -X POST https://localhost:3000/api/seed
```

This creates:

- the **owner** account (`eigenaar@leopoldlaan.test` / `changeme123`, override with `SEED_OWNER_EMAIL`, `SEED_OWNER_PASSWORD`, `SEED_OWNER_NAME`);
- 15 **werkposten** (categories) in the usual order of a Belgian renovation, each with a colour and icon;
- typical **rooms** per floor;
- five **phases** with a chain of starter tasks that depend on each other, plus two **milestones** (electrical inspection, moving in);
- two empty **Mijn VerbouwPremie** subsidies to fill in;
- five open **decisions** (heating, ventilation, sockets, floor finish, kitchen) with deadlines.

Add `?demo` (`/api/seed?demo`) to also get a demo contractor, budget lines, an approved quote and an invoice.

The seed is idempotent: it skips the owner if the e-mail exists and skips the structure if categories or phases already exist.

## 5. Log in

Open `https://localhost:3000` — you're redirected to `/login`.
