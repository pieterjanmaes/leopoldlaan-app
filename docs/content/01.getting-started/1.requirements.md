## Node.js 24+

`nuxt-security@2.6+` declares `engines.node >=24.0.0`, so the project needs **Node.js 24 or newer**.

```bash
node --version
# v24.x or higher
```

With [nvm](https://github.com/nvm-sh/nvm): `nvm install 24 && nvm use 24`.

## pnpm

The lockfile is `pnpm-lock.yaml`, so use **pnpm**. The exact version is pinned under `"packageManager"` in `package.json`; settings such as `shamefullyHoist: true` live in `pnpm-workspace.yaml` (pnpm 11+ no longer reads them from `.npmrc`).

```bash
npm install -g pnpm
pnpm --version
```

## Local HTTPS certificates (recommended)

The dev server uses HTTPS when `localhost.pem` and `localhost-key.pem` exist in the project root, and plain HTTP otherwise. HTTPS is closest to production (secure cookies, Turnstile, Google OAuth redirect URIs).

```bash
npx mkcert create-ca                       # once per machine
npx mkcert create-cert --domains localhost
mv cert.crt localhost.pem
mv cert.key localhost-key.pem
```

The `.pem` files are gitignored.
