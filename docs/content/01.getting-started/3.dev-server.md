## Commands

```bash
pnpm run dev          # https://localhost:3000
pnpm run lint         # oxlint (type-aware) + eslint
pnpm run format       # oxfmt
pnpm run test         # vitest
pnpm run db:generate  # migration after a schema change
pnpm run db:studio    # Drizzle Studio on the local DB
```

## Local data

| Path | What |
|---|---|
| `.data/db/sqlite.db` | The local D1 stand-in (libsql) |
| `.env` | Secrets for local development |

Reset the database and start over:

```bash
rm -f .data/db/sqlite.db .data/db/sqlite.db-shm .data/db/sqlite.db-wal
pnpm run dev
curl -k -X POST 'https://localhost:3000/api/seed?demo'
```

## Logging in as an external

To see the app the way a contractor does: Instellingen → Gebruikers → **Iemand uitnodigen**, role *Extern*, linked to a contact. Open the invite link in a private window and create the account. Assign a task to that contact to see it appear.

## Running inside a git worktree

If the project is checked out as a worktree *inside* another checkout (for example `.claude/worktrees/…`), see [Worktree tsconfig error](/troubleshooting/worktree-tsconfig).
