title: Setup
description: Create the Google OAuth client and connect the project's Drive.
---

Files live in **your own Google Drive**, in one project folder. The owner connects Drive once; everybody else — including contractors without a Google account — reaches the files through the server.

## 1. Google Cloud project

1. Open [console.cloud.google.com](https://console.cloud.google.com/) and create a project, e.g. *Leopoldlaan*.
2. **APIs & Services → Library**: enable the **Google Drive API**.

## 2. OAuth consent screen

1. **User type: External**. Fill in app name and your e-mail.
2. **Scopes**: add `.../auth/drive` (full Drive access) and `email`.
3. **Publish the app → In production.**

::warning
In *Testing* mode Google expires refresh tokens after **7 days**, and the connection silently breaks a week later. In production but unverified, the app works for up to 100 users; you'll click through a "Google hasn't verified this app" warning once when connecting. Only the owner ever sees that screen.
::

## 3. OAuth client

**Credentials → Create credentials → OAuth client ID → Web application.** Authorized redirect URIs:

```
https://localhost:3000/auth/google-drive
https://<your-domain>/auth/google-drive
```

## 4. Environment

```bash
NUXT_OAUTH_GOOGLE_CLIENT_ID=…apps.googleusercontent.com
NUXT_OAUTH_GOOGLE_CLIENT_SECRET=…
NUXT_DRIVE_TOKEN_KEY=…   # 32+ random characters, encrypts the stored refresh token
```

Deployed: set all three as Wrangler secrets (see [Cloudflare & Wrangler](/deployment/cloudflare-and-wrangler)). Until they're set, Instellingen shows *Nog niet geconfigureerd*.

## 5. Connect

As the owner: **Instellingen → Google Drive → Koppel Google Drive**, pick the Google account and allow access. On the first connection the app creates a folder **"Verbouwing – <project name>"** in My Drive and uses it as the project folder.

To use an existing folder instead, paste its Drive link in the field under the connection and click *Gebruik deze map*.

## Why the full `drive` scope?

The narrower `drive.file` scope only shows files the app created or that were picked through Google's own Picker — files you add to the folder from your phone's Drive app would be invisible. Because only the owner connects, and the server limits everyone to the project folder, the full scope is the practical choice for a household app.
